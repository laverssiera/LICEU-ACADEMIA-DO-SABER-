# Frontend (Next.js)

Aplicacao frontend principal em Next.js para jornada web da plataforma LICEU.

## Visao Geral

Este README descreve o contexto, a execucao e a operacao deste modulo no ecossistema LICEU.

## Stack

- Next.js 15
- React 19
- Tailwind CSS
- Zustand
- Framer Motion

## Porta

- Local: 3000
- Docker Compose: 8080 (mapeamento 8080 -> 3000)

## Execucao local

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev`: desenvolvimento local
- `npm run build`: build de producao
- `npm run start`: servidor Next em producao
- `npm run lint`: lint do app
- `npm run test`: placeholder de testes

## Variaveis de ambiente

Este servico nao possui variaveis obrigatorias documentadas no codigo atual.
