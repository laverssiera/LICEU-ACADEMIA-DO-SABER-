# Infra Docker

Artefatos relacionados a conteinerizacao e operacao local com Docker.

## Visao Geral

Subdominio de infraestrutura focado em conteinerizacao e suporte ao ciclo local de desenvolvimento.

## Objetivo

Centralizar utilitarios de suporte para execucao e troubleshooting de ambientes containerizados.

## Relacao com o projeto

- O bootstrap principal do ambiente local esta em docker-compose.yml na raiz.
- Este diretorio complementa a operacao com documentacao/auxiliares de infraestrutura.
