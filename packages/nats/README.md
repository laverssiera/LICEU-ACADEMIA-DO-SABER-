# NATS Package

Pacote compartilhado para contratos/eventos NATS.

## Visao Geral

Centraliza convencoes de eventos e integracoes com mensageria para os servicos da plataforma.

## Conteudo

- events.ts: eventos publicados/consumidos no ecossistema

## Dependencias

- nats

## Objetivo

Padronizar nomes de eventos e reduzir divergencia entre produtores e consumidores.
