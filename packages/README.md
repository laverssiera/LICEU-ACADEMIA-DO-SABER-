# Packages

Bibliotecas compartilhadas do monorepo para reutilizacao entre servicos.

## Visao Geral

Camada de compartilhamento de contratos, tipos e utilitarios para reduzir duplicacao no ecossistema.

## Estrutura

- auth: utilitarios de autenticacao/autorizacao (placeholder)
- nats: eventos e integracao NATS
- sdk: ponto de entrada para SDK interno (placeholder)
- shared-types: tipos compartilhados (placeholder)
- telemetry: helpers de telemetria (placeholder)
- ui: primitivos de UI compartilhados (placeholder)
- websocket: adaptadores websocket (placeholder)

## Diretriz

Concentrar contratos, tipos e utilitarios transversais para evitar duplicacao entre apps.
